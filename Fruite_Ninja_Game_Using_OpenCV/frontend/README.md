# Fruit Ninja AR — React.js Frontend

Modern, high-performance Fruit Ninja game frontend built with React 19, Vite, HTML5 Canvas, and Google MediaPipe hand tracking.

## Quick Start

```bash
# Install dependencies
npm install

# Start Vite development server
npm run dev

# Build production bundle
npm run build

# Preview production build
npm run preview
```

## Features

- **MediaPipe Hand Tracking**: Real-time 60 FPS index fingertip detection (Landmark 8) with neon Katana reticle and skeletal overlay.
- **Fullscreen Live Camera Feed**: Mirrored camera stream directly behind the transparent canvas.
- **1P Solo & 2P Split-Screen**: Survival mode and side-by-side duel mode.
- **High-Definition Assets**: Studio-grade realistic fruit textures and sliced cutouts.
- **Web Audio API**: Spatial sounds for slicing, bomb explosion, combos, and UI.
